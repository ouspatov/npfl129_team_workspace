# Introduction to Machine Learning with Python - NPFL129

Shared repository for a team of 3 working on the NPFL129 course. This is the collaboration repo.

## Installation

**macOS / Linux**

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

**Windows**

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```
